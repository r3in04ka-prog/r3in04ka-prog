# Profile collage assets

These five bitmap graphics implement the profile owner's selected fourth visual direction: black/red/ivory independent-zine collage, torn paper, oversized typography, portrait and barcode details. Generated with the built-in OpenAI image generation tool on 2026-11-15 using the owner's supplied visual identity screenshot and selected profile concept as references. The uploaded source screenshots are not included here.

- `hero.png`: 1600×900-target hero composition; stacked RE/IN/O/CHKA typography at left, referenced portrait in the center, red manifesto paper at right. Exact copy: “Идеи — мои. Возможности — шире.”, “Создаю цифровые продукты и автоматизацию с ИИ.”, “СВОИ ИДЕИ. СВОЙ ПОДХОД. СВОЙ ПОЧЕРК.”
- `cashed.png`: tall ivory torn-paper poster with CASHED!, “цифровое ателье”, printed black/red/cream geometry, barcode and “БРЕНД / ДИЗАЙН / САЙТ”.
- `cashed-wide.png`: horizontal adaptation generated on 2026-11-16 from the tall poster, with the same title, subtitle, palette and printed geometry. Used in the full-width project list so the profile remains readable on narrow screens. Other cards keep their original artwork and natural aspect ratios.
- `smile-talk.png`: wide black torn-paper ticket, cream SMILE TALK, “автоматизация клиники”, vermilion registration mark and barcode.
- `purrsonal.png`: wide ivory torn-paper ticket with exact title Purrsonal, “ИИ-котик для рабочего стола”, orange kitten from the Purrsonal project as a cutout, red underline and barcode.
- `euphoria.png`: wide red paper strip, Euphoria, “сайт салона”, “В РАЗРАБОТКЕ”, black arrow.

Shared production brief: flat final README artwork only; near-black distressed paper, saturated vermilion and warm ivory; no GitHub shell, fake controls, contact details, invented statistics, neon or gradients. Text belongs to each bitmap. Images retain natural aspect ratios and link to their respective project pages in the profile README. The native GitHub sidebar is not part of the artwork.
